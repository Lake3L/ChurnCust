# BACKLOG — кладбище хороших идей

Правило: любая идея вне скоупа записывается сюда одной строкой и не трогается до конца проекта.

- [ ] Uplift-моделирование вместо churn-скоринга (T-learner / uplift trees): честнее отвечает на вопрос «кому звонить», но требует данных об интервенциях.
- [ ] SHAP-объяснения в ответе API (`/predict` возвращает топ-факторы решения).
- [ ] Prometheus + Grafana вместо ручного `/metrics`.
- [ ] Батч-скоринг по расписанию (cron-контейнер) с записью в отдельную таблицу.
- [ ] A/B-симулятор кампании удержания на исторических данных.
- [ ] Разные V и C для сегментов клиентов (порог становится персональным).
- [ ] Онлайн-мониторинг калибровки (rolling Brier score по логам предсказаний).
- [ ] Временная валидация вместо случайного сплита (train на кварталах t, тест на t+1) — требует данных с временной меткой.
- [ ] Оптимизировать в Optuna напрямую ожидаемую прибыль на valid вместо PR-AUC и сравнить выбранные модели.
- [ ] Детектор concept drift на отложенных метках: считать PR-AUC на «дозревших» клиентах и алертить на падение.
- [ ] Калибровать порог PSI-алерта по историческим окнам вместо эвристики 0.2 (текущий порог пропускает prior shift).
- [ ] Асинхронная запись предсказаний (очередь/батч) — синхронный INSERT в Postgres первым упрётся в потолок при 1000 RPS.
- [ ] Мультиворкерный uvicorn/gunicorn + нагрузочный тест locust (сейчас замер на 1 воркере).
